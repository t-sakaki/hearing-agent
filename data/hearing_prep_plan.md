## コマンド（コピー用）

作業はすべて、ぺいくんが自分で開いた **WSL ターミナル** で行う。

```bash
cd /mnt/c/Users/taira/hearing-agent
```

### 精度テスト（実マイク、約 20 秒）

読み上げ原稿は `data/mic_script.txt`（架空）。`[Windows] Recording via PowerShell -> DirectShow...` のあと、ffmpeg のログが出てから読み始める。

```bash
cat data/mic_script.txt
bash scripts/run_m7_mic.sh --seconds 20 --clear-stop
```

`decision>` では `a`（承認）/ `e`（編集承認）/ `r`（却下）。詳細は `data/mic_test_procedure.md` および `data/mic_instructions.md`。

録音だけ先に試す場合:

```bash
bash scripts/record_mic.sh 20
# または PowerShell:
# powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\Users\taira\hearing-agent\scripts\record_mic.ps1 -Seconds 20
```

### STOP テスト

```bash
bash scripts/run_m7_mic.sh --seconds 20 --clear-stop
```

読み上げのあと、`decision>` で **`STOP`** と入力して Enter。期待: `killed`、TTS なし。フラグが残ったら:

```bash
rm -f /mnt/c/Users/taira/hearing-agent/runtime/STOP /mnt/c/Users/taira/hearing-agent/output/STOP
```

別ターミナルから試す場合: `touch /mnt/c/Users/taira/hearing-agent/runtime/STOP`

### 模擬リハーサル（処分庁役）

専用の自動スクリプトはリポジトリにない。ボット（または edge-tts）が `data/mock_rehearsal_agency.md` の質問を読み、ぺいくんが答えたあと、必要なら同じ `run_m7_mic.sh` で応答を文字起こし・ドラフト・承認する。**実事件の文書は使わない（未受領）。** 有料 API は見積もりなしに呼ばない。

### 片付け（テスト用 WAV）

```bash
rm -f /mnt/c/Users/taira/hearing-agent/data/mic/mic_*.wav
rm -f /mnt/c/Users/taira/hearing-agent/runtime/STOP /mnt/c/Users/taira/hearing-agent/output/STOP
```

ログと承認済み MP3 は残してよい。11/11 の無音 WAV は、再テストが合格するまで残して構わない。

## 合格・不合格の目安（精度テスト）

- **不合格の例（11/11 実績）:** ピーク約 −48 dBFS、RMS 約 −84 dBFS、STT 空、用語 0/5。この場合は設定を直して録り直す。
- **合格の目安:** 発話区間が波形で分かる。用語が概ね出る（完全一致でなくてよいが、空や全く別語ばかりは不可）。ゲートを通ったときだけ TTS がある。
